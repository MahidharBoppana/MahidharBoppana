### 📝 NoteFlow

**Full-Stack Note Taking Application**

A full-stack note management application built with the MERN stack featuring secure authentication and complete note management.

**Key Features**

* JWT authentication and protected REST APIs
* Create, read, update, and delete notes
* Search functionality
* Pin and unpin notes
* Soft delete and trash management
* Restore deleted notes
* Permanent note deletion
* MongoDB relationships
* Reusable Express controllers and middleware
* Responsive user interface

**Tech Stack:** React.js • Node.js • Express.js • MongoDB • JWT
