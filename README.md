<h2 align="center">🌟 Featured Project</h2>

<div align="center">

# 🤖 HireSense AI

### *Screen resumes in seconds. Rank the best candidates automatically.*

</div>

> **HireSense AI** is an AI-powered Applicant Tracking System designed to help recruiters analyze resumes, match candidates against job descriptions, and automatically rank applicants.

### ✨ What makes it interesting?

```text
Resume
   │
   ▼
┌─────────────────┐
│ Document Parser │
└────────┬────────┘
         │
         ▼
┌─────────────────┐
│   AI Analysis   │
└────────┬────────┘
         │
         ▼
┌─────────────────┐
│ Semantic Match  │
└────────┬────────┘
         │
         ▼
┌─────────────────┐
│ Candidate Score │
└────────┬────────┘
         │
         ▼
┌─────────────────┐
│ 🏆 Ranking      │
└─────────────────┘
```

**Core features**

* 🤖 AI-powered resume analysis
* 📄 PDF/DOCX resume processing
* 🎯 Job description matching
* 🧠 Semantic similarity
* 📊 Candidate scoring & ranking
* 👥 Role-based access control
* 🔐 Secure authentication
* 📈 Recruiter analytics
* 📤 Data export

**Stack**

`React` `Node.js` `Express` `MongoDB` `Redis` `AI/LLMs` `REST APIs`
